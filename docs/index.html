毎日の入力を、暦の上に。

キーボードとマウスを 1 日 1 マスで記録する、ローカル完結のデスクトップアプリ。

Windows 版 macOS 版

MIT License ・ 約 5 MB ・ Windows 10/11 ・ macOS 10.15+

インストール時の注意 (初回のみ)

Windows

  1. インストーラを実行
  2. SmartScreen の警告 → 「詳細情報」→「実行」

macOS

  1. .dmg を開き Clack.app を Applications にドラッグ
  2. アプリを 右クリック → 開く (初回のみ)
  3. 「検証できませんでした」と出たら、システム設定 → プライバシーとセキュリティで このまま開く
  4. 入力監視 と アクセシビリティ で Clack を ON

記録

1 日が 1 マス。365 日がひと目に。

濃いマスはよく打った日、淡いマスはひと休み。キーとマウスを合わせた活動量で 5 段階に色分けされ、1ヶ月から 12ヶ月まで自由に伸縮できます。

マスにカーソルを合わせれば日付ごとの内訳が、過去に遡れば任意の月の動きが浮かびます。

分析

数字の奥にある癖を、静かに浮かばせる。

連続入力した日数、アクティブ時間、最も使ったキー、時間帯ごとの活動量。スコープは今日 / 7 日 / 今月 / 全期間からワンクリックで切り替わります。

キーとマウスの内訳は降順の横棒チャート。Shift + 1 のような同時押しは 1 つにまとまり、ノイズの少ない読みやすい結果に整います。

旅

マウスで歩いて、スクロールで宇宙へ。

カーソルの移動距離とスクロール量を毎日記録し、富士山・東京タワー・国際宇宙ステーションなどのランドマークと比較。普段の作業が、ささやかな旅になります。

単位は m / km。「今日 48 m」「累計で富士山を 1.2 倍登った」など、控えめな数字でそっと寄り添います。

リアルタイム

目の端で、流れていく。

常に最前面に置ける小窓に、押したキーが即時に並びます。Shift + 1 のような同時押しは 1 つに統合され、読みやすい流れに整います。

入力が止まれば窓も自然に縮む。スタックモードに切り替えれば、直近 100 件まで残せます。

バックアップ

持ち出すのも、戻すのも、1 クリック。

全データを JSON で完全エクスポート / インポート、CSV で表計算ソフト用に書き出し。バックアップから戻すときは 2 段階確認が入るので、誤上書きの心配はありません。

CSV の列は date,keys,mouse,total,h0..h23。時間帯別カラムを含むので、ExcelやNotebookでそのまま分析に使えます。

.json 完全バックアップ
.csv 表計算ソフト用
⌫ 完全削除 (確認あり)

プライバシー

ネットワーク呼び出しは、0 件。

HTTP や TCP を扱うライブラリはコードに含まれていません。データは端末内のユーザーデータディレクトリ ─ Windows なら %APPDATA%\Clack\、macOS なら ~/Library/Application Support/Clack/ ─ に置かれ、端末を離れる構造的な経路がそもそも存在しません。打鍵の順序やタイミングは記録せず、保存されるのはキー識別子の回数だけ。すべて MIT ライセンスで公開されており、確認は grep から始められます。
